# Proyectos de Alejandro Pigón

[Abrir la página](https://alejandropico.github.io/Proyectos/)

Acceso directo a los proyectos públicos de AlejandroPico, del más reciente al más antiguo según su fecha de creación. Excluye Inversor y los privados.

Página estática sin dependencias, fuentes externas, animaciones ni consultas a la API al abrir. Los enlaces funcionan sin JavaScript. Iconos diferidos con alternativa si fallan. Presentación en fichas o lista y enlaces a cada aplicación publicada y a su repositorio.

## Actualizar

Editar `projects.json` y ejecutar `node build.mjs`. Subir también el `index.html` generado. Solo añadir proyectos cuya visibilidad pública se haya comprobado.

## Publicar

GitHub Pages desde la rama `main`, carpeta raíz. No requiere instalación ni compilación en el servidor.
